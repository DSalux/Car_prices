# Как запускать проект Car Prices

Этот файл описывает полный алгоритм запуска ноутбука и Streamlit-приложения для прогноза цены автомобиля.

## 1. Клонировать репозиторий

```bash
git clone https://github.com/DSalux/Car_prices.git
cd Car_prices
```

## 2. Создать виртуальное окружение

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

## 3. Установить зависимости

```bash
pip install -r requirements.txt
```

## 4. Запустить Streamlit-приложение

```bash
streamlit run app.py
```

После запуска Streamlit покажет локальную ссылку, обычно:

```text
http://localhost:8501
```

Откройте эту ссылку в браузере.

## 5. Как пользоваться приложением

1. Выберите марку автомобиля в поле `Марка`.
2. Укажите год выпуска.
3. Введите пробег в километрах.
4. Выберите тип топлива.
5. Выберите коробку передач.
6. Укажите владельца по счету, объем двигателя и количество мест.
7. Выберите валюту результата: `INR`, `USD`, `EUR` или `RUB`.
8. Приложение автоматически покажет ориентировочную цену.

Модель обучена на индийском датасете, поэтому базовый прогноз считается в индийских рупиях. Если выбрана другая валюта, приложение конвертирует цену из INR по онлайн-курсу. Если онлайн-курс временно недоступен, используется запасной примерный курс, и приложение показывает предупреждение.

## 6. Откуда берутся данные

Проект использует датасет Kaggle `Old Car Price Prediction`:

https://www.kaggle.com/datasets/milanvaddoriya/old-car-price-prediction

Если файла `data/car_price.csv` нет, приложение и завершенный ноутбук попробуют скачать датасет автоматически через Kaggle API URL.

Если автоматическое скачивание не сработало, скачайте датасет вручную и положите файл:

```text
data/car_price.csv
```

## 7. Как запустить анализ в ноутбуке

Откройте файл:

```text
Car_prices_completed.ipynb
```

И выполните все ячейки сверху вниз.

Ноутбук делает:

1. загрузку данных;
2. очистку цены, пробега, двигателя и количества мест;
3. EDA и графики;
4. обучение baseline-модели;
5. обучение RandomForest и GradientBoosting;
6. сравнение моделей по MAE, RMSE и R2;
7. анализ важных и менее важных признаков;
8. сохранение модели в `artifacts/car_price_model.joblib`.

## 8. Что считается готовым результатом

После успешного запуска должны появиться:

```text
artifacts/car_price_model.joblib
artifacts/car_price_model_metadata.json
```

Streamlit-приложение использует сохраненную модель, если она уже есть. Если модели нет, приложение обучит ее заново на датасете.

## 9. Как работает конвертация валют

Модель всегда предсказывает цену в INR, потому что целевая переменная исходного датасета - `car_prices_in_rupee`.

В приложении можно выбрать валюту вывода:

```text
INR
USD
EUR
RUB
```

Алгоритм такой:

1. модель предсказывает цену в INR;
2. приложение загружает актуальные курсы относительно INR;
3. выбранная валюта умножается на курс;
4. пользователь видит итоговую цену в выбранной валюте;
5. если курс не загрузился, приложение использует запасные примерные курсы и показывает предупреждение.

## 10. Быстрая проверка работоспособности

Выполните:

```bash
python -m py_compile app.py
streamlit run app.py
```

Если страница открылась, поля отображаются, можно выбрать валюту и есть блок `Ориентировочная цена`, приложение работает.
