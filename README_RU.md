# Car Prices

ML-проект для прогнозирования стоимости подержанных автомобилей по характеристикам объявления. Проект начался как ноутбук с анализом данных, а затем был доведен до воспроизводимого pet-проекта: модель, анализ признаков, Streamlit-приложение, конвертация валют, Docker, тесты, CI и эксперимент на другом рынке.

## Что делает проект

- Очищает исходные данные, где цена, пробег, объем двигателя и количество мест записаны текстом.
- Обучает регрессионные модели для оценки стоимости автомобиля.
- Сравнивает baseline, RandomForest и GradientBoosting.
- Сохраняет лучшую модель как scikit-learn `Pipeline`.
- Дает интерактивное Streamlit-приложение для прогноза цены.
- Конвертирует базовый прогноз из `INR` в `USD`, `EUR` или `RUB`.
- Проверяет переносимость модели на другой рынок на датасете автомобилей из Австралии.

## Основной датасет

Основная модель обучается на Kaggle-датасете `Old Car Price Prediction`:

https://www.kaggle.com/datasets/milanvaddoriya/old-car-price-prediction

Целевая переменная в датасете — `car_prices_in_rupee`, поэтому базовый прогноз модели считается в индийских рупиях.

## Результаты

Лучшие результаты на основном индийском датасете:

| Модель | MAE | RMSE | R2 |
|---|---:|---:|---:|
| RandomForest | 342,919 INR | 837,369 INR | 0.770 |
| GradientBoosting | 365,509 INR | 892,227 INR | 0.739 |
| Baseline median | 771,762 INR | 1,826,970 INR | -0.095 |

Кросс-валидация для RandomForest по MAE:

```text
369,285 +/- 77,750 INR
```

## Streamlit-приложение

Локальный запуск:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Открыть в браузере:

```text
http://localhost:8501
```

В приложении можно выбрать:

- марку автомобиля;
- год выпуска;
- пробег;
- тип топлива;
- коробку передач;
- количество владельцев;
- объем двигателя;
- количество мест;
- валюту результата.

## Docker

## Эксперимент с переносом на другой рынок

В проект добавлен отдельный эксперимент на Kaggle-датасете `Australian Vehicle Prices`:

https://www.kaggle.com/datasets/nelgiriyewithana/australian-vehicle-prices

Запуск:

```bash
python domain_shift_australia.py
```

Сравнение результатов:

| Модель | MAE AUD | RMSE AUD | R2 |
|---|---:|---:|---:|
| AU RandomForest with extended features | 5,273 | 13,462 | 0.778 |
| Baseline median on AU | 16,737 | 29,264 | -0.050 |
| India model transferred to AU | 18,102 | 28,151 | 0.028 |

Вывод: модель, обученная на одном рынке, плохо переносится на другой без переобучения. Для другого региона лучше обучать отдельную модель на локальных данных и добавлять признаки, важные именно для этого рынка.

## Ограничения

- Основная модель обучена на индийском рынке подержанных автомобилей.
- Прогноз является ориентировочной оценкой, а не гарантированной рыночной ценой.
- В основном датасете нет части важных факторов: состояние автомобиля, аварийность, комплектация, регион, история обслуживания и тип продавца.
- Конвертация валют не делает модель глобальной: она только переводит сумму из INR в другую валюту.
- Для другой страны или региона модель лучше переобучать на локальном датасете.
